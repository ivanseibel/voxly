## How to use this file

This file tracks only open work: bugs still to fix, features still to build,
decisions still to make. Finished work is not recorded here — the git history is
the record of what was done, and design rationale that stays relevant lives in
comments next to the code it explains.

Add an entry as a `###` section describing the current behaviour, the observable
effects, and the intended fix. Remove the entry once it ships.
